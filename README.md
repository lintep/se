# سیستم مدیریت کتابخانه دانشگاه

یک برنامه‌ی کنسولی (خط فرمان) به زبان **Java** برای مدیریت کتابخانه‌ی دانشگاه. این پروژه با رویکرد شی‌گرا پیاده‌سازی شده و چهار نقش **دانشجو، کارمند، مدیر و مهمان** را پشتیبانی می‌کند. اطلاعات در یک پایگاه داده‌ی **SQLite** ذخیره می‌شوند و در اجرای بعدی بازیابی می‌گردند.

## امکانات

### دانشجو
- ورود به سیستم و تغییر رمز عبور
- جستجوی کتاب بر اساس ترکیبی از عنوان، سال نشر و نام نویسنده
- مشاهده وضعیت کتاب (موجود / امانت داده شده)
- ثبت درخواست امانت کتاب با تعیین تاریخ شروع و پایان
- مشاهده تاریخچه امانت‌ها

### کارمند
- ثبت کتاب جدید و ویرایش اطلاعات کتاب
- بررسی و تایید درخواست‌های امانت (فقط درخواست‌هایی که تاریخ شروع آن‌ها امروز یا دیروز است)
- ثبت دریافت کتاب بازگشتی
- مشاهده گزارش و آمار امانت‌های هر دانشجو (تعداد کل، تحویل نشده، با تاخیر)
- فعال/غیرفعال کردن دانشجو
- تغییر رمز عبور

### مدیر
- تعریف کارمند جدید (نام کاربری، رمز عبور و نام)
- مشاهده عملکرد کارمندان (کتاب‌های ثبت‌شده، امانت‌داده‌شده و تحویل‌گرفته‌شده)
- مشاهده آمار امانت‌ها (تعداد درخواست‌ها، امانت‌ها و میانگین مدت امانت)
- مشاهده آمار کلی دانشجویان (دانشجویان با بیشترین تاخیر)
- تغییر رمز عبور

### مهمان (بدون نیاز به ورود)
- مشاهده تعداد دانشجویان ثبت‌نام‌شده
- جستجوی کتاب فقط بر اساس عنوان
- مشاهده آمار ساده (تعداد دانشجویان، کتاب‌ها، کل امانت‌ها و امانت‌های جاری)

## ساختار پروژه

پروژه یک پروژه‌ی **Maven** با ساختار استاندارد است (پکیج پایه: `znulib`):

```
se/
├── pom.xml                                   تنظیمات Maven و وابستگی‌ها
├── README.md
└── src/main/java/znulib/
    ├── UniversityLibrarySystem.java          نقطه‌ی شروع برنامه (main)
    ├── model/                                موجودیت‌ها
    │   ├── User.java                         کلاس پایه‌ی انتزاعی کاربران
    │   ├── Student.java                      دانشجو
    │   ├── Employee.java                     کارمند
    │   ├── Manager.java                      مدیر
    │   ├── Guest.java                        مهمان
    │   ├── Book.java                         کتاب
    │   ├── LoanRequest.java                  درخواست امانت
    │   └── Loan.java                         امانت
    ├── service/
    │   └── LibrarySystem.java                منطق اصلی و منوها
    ├── statistics/                           گزارش‌ها و آمار
    │   ├── StudentStatistics.java
    │   ├── StudentOverallStatistics.java
    │   ├── EmployeeStatistics.java
    │   ├── LoanStatistics.java
    │   └── GuestStatistics.java
    ├── storage/
    │   └── DataStore.java                    ذخیره‌سازی در SQLite
    └── util/
        └── DateUtil.java                     ابزارهای کمکی
```

درایور SQLite (`org.xerial:sqlite-jdbc:3.41.2.2`) به‌عنوان وابستگی در `pom.xml` تعریف شده و Maven آن را خودکار از Maven Central دانلود می‌کند؛ نیازی به پوشه‌ی `libs` یا jar محلی نیست.

## پیش‌نیازها

- **JDK نسخه ۸ یا بالاتر**
- **Apache Maven نسخه ۳.۶ یا بالاتر** (یا استفاده از Maven داخلی IntelliJ IDEA)
- دسترسی به اینترنت در اولین build (برای دانلود وابستگی‌ها)
- ترمینالی که از **UTF-8** پشتیبانی کند (منوها و پیام‌ها فارسی هستند)

بررسی نصب بودن ابزارها:

```bash
java -version
mvn -version
```

## نحوه‌ی اجرا

### ۱) ساخت jar اجرایی (پیشنهادی)

```bash
mvn clean package
java -Dfile.encoding=UTF-8 -jar target/library-system.jar
```

این jar شامل درایور SQLite هم هست و روی هر سیستمی که جاوا دارد اجرا می‌شود.

### ۲) اجرای مستقیم با Maven

```bash
mvn compile exec:java
```

> اگر متن فارسی درست نمایش داده نشد: در ویندوز قبل از اجرا `chcp 65001` را بزنید و از Windows Terminal استفاده کنید؛ برای حالت `exec:java` مقدار `MAVEN_OPTS=-Dfile.encoding=UTF-8` را هم تنظیم کنید.

### ۳) از طریق IntelliJ IDEA

1. از **File → Open** فایل `pom.xml` را انتخاب کنید و گزینه‌ی *Open as Project* را بزنید.
2. صبر کنید تا Maven وابستگی‌ها را دانلود کند.
3. فایل `UniversityLibrarySystem.java` را باز کنید و روی دکمه‌ی **Run** کنار متد `main` بزنید.

## حساب‌ها و داده‌های نمونه

هنگام اجرا، داده‌های زیر به‌صورت پیش‌فرض ساخته می‌شوند:

| نقش | نام کاربری | رمز عبور |
|-----|-----------|----------|
| مدیر | `admin` | `admin123` |
| کارمند | `emp1` | `123` |
| دانشجو | `stu1` | `123` |
| دانشجو | `stu2` | `123` |

همچنین سه کتاب نمونه («آموزش جاوا»، «پایگاه داده»، «هوش مصنوعی») و یک درخواست امانت نمونه برای `stu1` وجود دارد که کارمند می‌تواند آن را تایید کند.

## ذخیره‌سازی اطلاعات

- اطلاعات در فایل پایگاه داده‌ی `library.db` کنار محل اجرای برنامه (پوشه‌ی جاری) ذخیره می‌شود و در اولین اجرا خودکار ساخته می‌شود.
- جدول‌ها: `manager`، `students`، `employees`، `books`، `loan_requests`، `loans` (با کلید خارجی بین آن‌ها).
- در اولین اجرا (وقتی پایگاه داده خالی است) داده‌های نمونه ساخته و ذخیره می‌شوند؛ از اجرای بعدی اطلاعات از پایگاه داده خوانده می‌شود.
- ذخیره‌سازی در ابتدای هر بار نمایش منوها و در قالب یک تراکنش انجام می‌شود (کل وضعیت سیستم بازنویسی می‌شود)، پس اگر خطایی رخ دهد داده‌ی قبلی سالم می‌ماند.
- اگر درایور در classpath نباشد (مثلاً کلاس‌ها بدون Maven اجرا شوند)، برنامه با پیام `درایور SQLite پیدا نشد` متوقف می‌شود.

## نمونه‌ی سناریوی استفاده

1. برنامه را اجرا کنید و گزینه‌ی **۱ (ورود دانشجو)** را با `stu2` / `123` انتخاب کنید.
2. با گزینه‌ی **درخواست امانت کتاب**، یک کتاب را انتخاب کنید و تاریخ‌ها را با قالب `YYYY-MM-DD` وارد کنید (تاریخ شروع را **امروز** بگذارید).
3. خارج شوید و با `emp1` / `123` به‌عنوان **کارمند** وارد شوید.
4. از گزینه‌ی **بررسی درخواست‌های امانت** درخواست را تایید کنید.
5. بعد از برگشت کتاب، گزینه‌ی **ثبت دریافت کتاب بازگشتی** را بزنید.
6. با `admin` / `admin123` به‌عنوان **مدیر** وارد شوید و آمار را ببینید.

## نکات و محدودیت‌ها

- برای بازگشت به داده‌های نمونه‌ی اولیه، فایل `library.db` را حذف کنید.
- رمزهای عبور به‌صورت متن ساده نگهداری می‌شوند (مناسب فقط برای پروژه‌ی آموزشی).
- در منوی برنامه گزینه‌ای برای ثبت‌نام دانشجوی جدید وجود ندارد (متد `registerStudent` در `LibrarySystem` موجود است ولی به منو متصل نشده است).
- تایید درخواست امانت فقط برای درخواست‌هایی ممکن است که تاریخ شروعشان **امروز یا دیروز** باشد.
