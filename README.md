# سیستم مدیریت کتابخانه دانشگاه

یک برنامه‌ی کنسولی (خط فرمان) به زبان **Java** برای مدیریت کتابخانه‌ی دانشگاه. این پروژه با رویکرد شی‌گرا پیاده‌سازی شده و چهار نقش **دانشجو، کارمند، مدیر و مهمان** را پشتیبانی می‌کند. تمام داده‌ها در حافظه نگهداری می‌شوند و با بستن برنامه از بین می‌روند.

## امکانات

### دانشجو
- ورود به سیستم و تغییر رمز عبور
- جستجوی کتاب بر اساس ترکیبی از عنوان، سال نشر و نام نویسنده
- مشاهده وضعیت کتاب (موجود / امانت داده شده)
- ثبت درخواست امانت کتاب با تعیین تاریخ شروع و پایان
- مشاهده تاریخچه امانت‌ها

### کارمند
- ثبت کتاب جدید و ویرایش اطلاعات کتاب
- بررسی و تایید درخواست‌های امانت (فقط درخواست‌هایی که تاریخ شروع آن‌ها امروز یا دیروز است)
- ثبت دریافت کتاب بازگشتی
- مشاهده گزارش و آمار امانت‌های هر دانشجو (تعداد کل، تحویل نشده، با تاخیر)
- فعال/غیرفعال کردن دانشجو
- تغییر رمز عبور

### مدیر
- تعریف کارمند جدید (نام کاربری، رمز عبور و نام)
- مشاهده عملکرد کارمندان (کتاب‌های ثبت‌شده، امانت‌داده‌شده و تحویل‌گرفته‌شده)
- مشاهده آمار امانت‌ها (تعداد درخواست‌ها، امانت‌ها و میانگین مدت امانت)
- مشاهده آمار کلی دانشجویان (دانشجویان با بیشترین تاخیر)
- تغییر رمز عبور

### مهمان (بدون نیاز به ورود)
- مشاهده تعداد دانشجویان ثبت‌نام‌شده
- جستجوی کتاب فقط بر اساس عنوان
- مشاهده آمار ساده (تعداد دانشجویان، کتاب‌ها، کل امانت‌ها و امانت‌های جاری)

## پیش‌نیازها

- **JDK نسخه ۸ یا بالاتر** (پروژه برای JDK 1.8 تنظیم شده است)
- ترمینالی که از **UTF-8** پشتیبانی کند (منوها و پیام‌ها فارسی هستند)

برای بررسی نصب بودن جاوا:

```bash
javac -version
java -version
```

## نحوه‌ی اجرا

### ۱) از طریق خط فرمان

در پوشه‌ی پروژه (جایی که فایل‌های `.java` قرار دارند):

```bash
# کامپایل
javac -encoding UTF-8 -d out *.java

# اجرا
java -Dfile.encoding=UTF-8 -cp out UniversityLibrarySystem
```

> در ویندوز اگر متن فارسی درست نمایش داده نشد، قبل از اجرا دستور `chcp 65001` را بزنید و از یک ترمینال با فونت مناسب (مثل Windows Terminal) استفاده کنید.

### ۲) از طریق IntelliJ IDEA

1. پوشه‌ی پروژه را با **File → Open** باز کنید.
2. SDK پروژه را روی JDK 8 یا بالاتر بگذارید.
3. فایل `UniversityLibrarySystem.java` را باز کنید و روی دکمه‌ی **Run** کنار متد `main` بزنید.

## حساب‌ها و داده‌های نمونه

هنگام اجرا، داده‌های زیر به‌صورت پیش‌فرض ساخته می‌شوند:

| نقش | نام کاربری | رمز عبور |
|-----|-----------|----------|
| مدیر | `admin` | `admin123` |
| کارمند | `emp1` | `123` |
| دانشجو | `stu1` | `123` |
| دانشجو | `stu2` | `123` |

همچنین سه کتاب نمونه («آموزش جاوا»، «پایگاه داده»، «هوش مصنوعی») و یک درخواست امانت نمونه برای `stu1` وجود دارد که کارمند می‌تواند آن را تایید کند.

## نمونه‌ی سناریوی استفاده

1. برنامه را اجرا کنید و گزینه‌ی **۱ (ورود دانشجو)** را با `stu2` / `123` انتخاب کنید.
2. با گزینه‌ی **درخواست امانت کتاب**، یک کتاب را انتخاب کنید و تاریخ‌ها را با قالب `YYYY-MM-DD` وارد کنید (تاریخ شروع را **امروز** بگذارید).
3. خارج شوید و با `emp1` / `123` به‌عنوان **کارمند** وارد شوید.
4. از گزینه‌ی **بررسی درخواست‌های امانت** درخواست را تایید کنید.
5. بعد از برگشت کتاب، گزینه‌ی **ثبت دریافت کتاب بازگشتی** را بزنید.
6. با `admin` / `admin123` به‌عنوان **مدیر** وارد شوید و آمار را ببینید.

## نکات و محدودیت‌ها

- داده‌ها در فایل یا پایگاه داده ذخیره نمی‌شوند؛ با خروج از برنامه همه‌چیز به حالت اولیه برمی‌گردد.
- رمزهای عبور به‌صورت متن ساده نگهداری می‌شوند (مناسب فقط برای پروژه‌ی آموزشی).
- در منوی برنامه گزینه‌ای برای ثبت‌نام دانشجوی جدید وجود ندارد (متد `registerStudent` در `LibrarySystem` موجود است ولی به منو متصل نشده است).
- تایید درخواست امانت فقط برای درخواست‌هایی ممکن است که تاریخ شروعشان **امروز یا دیروز** باشد.
